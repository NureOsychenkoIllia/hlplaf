# Lab3 Stream

Мінімалістичний Android/Kotlin застосунок для завдання 8 з кожного рівня: музичний стрімінг.

## Реалізовано

- Рівень 1: пошук композицій за жанром, виконавцем, альбомом та добірка "Прослухати пізніше".
- Рівень 2: прослуховування, завантаження, плейлисти та поділ музики за жанрами.
- Рівень 3: профіль користувача та створення/відстеження відгуків до треків.
- Рівень 4: локальна аналітика використання медіа-файлів: кількість прослуховувань і завантажень.

## Технічні рішення

- Kotlin + Jetpack Compose, без XML layout-файлів.
- Локальний `ViewModel` зі станом у пам'яті, без бекенду, щоб фокус був на Kotlin-практиці.
- Дані треків і стиль взято за мотивами `lab2` музичного стрімінгу.

## Перевірка

```bash
GRADLE_USER_HOME=/tmp/lab3-gradle-home ./gradlew assembleDebug
```
